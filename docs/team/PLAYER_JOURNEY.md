# プレイヤージャーニー

> Cycle 39 (Phase 0) 設計図。実装ゼロ、体験タイムラインを **時刻 × 画面 × 感情** で記述する。
> 後続フェーズ (機能封印 / コアループ修正 / スキル展開) はこのドキュメントを基準に判断する。
>
> 北極星 (`docs/team/MISSION.md`): 「攻略サイトでは絶対に答えが出せない、毎日帰りたくなるテキスト RPG」。
> このジャーニーで Day1〜Endgame の各フェーズで「帰りたくなる」フックを 1 つ以上作る。

---

## レイヤー設計

監督方針 (Q3 全部満たす + 時系列レイヤー):

| 時系列 | 主軸 | 達成感 |
|---|---|---|
| **Day 1** | ハクスラ | 戦闘で勝つ → 装備拾う → 装備で強くなる |
| **Week 1** | ビルド | 転職 + スキル継承 + 熟練度 で「自分のキャラ」 |
| **Month 1** | 物語 | curated NPC との関係 / シーズン謎 / lore docs 連動 |
| **Endgame** | マルチ | ギルド / レイド / シージ / 奈落 ランキング |

各フェーズで前フェーズの体験は **継続して動き続ける**。レイヤーが上に積み重なるイメージ。

## Day 1 (0〜60 分)

### 0〜15 分: 初接触

**画面遷移**:
- `/register` → email + password 入力 → 自動ログイン
- `/characters` → 「新規キャラクター作成（職業診断）」
- 名前入力 (2-24 字) → クイズ 6 問
- 結果サマリ画面: 「あなたに似た固有職」が紫枠で 1-2 体出る (curated 100 職から top archetype マッチ)
- 「○○ で始める」or 「テンプレ職で運命を委ねる」
- 自動 `/town` 遷移

**プレイヤーが感じること**:
- 「クイズで自分のキャラが決まった」自分ごと感
- 「★固有」バッジで「これは特別な職業らしい」期待
- 街の説明文と curated NPC のシルエットで世界観に入る

**懸念点 (Phase 1 で修正)**:
- 現状: 自動遷移後の「次に何をすべきか」が不明
- → HUD に「最初のクエスト: 戦いに出る」が常時表示されるべき

### 15〜30 分: 最初の戦闘

**画面遷移**:
- `/town` → 「戦いに出る」ボタン → 戦闘開始
- 敵 1 体、3-5 ターン続く (Phase 1 修正後)
- 攻撃 → スキル発動の機会あり (現状: 1 ターン決着でスキル空気)
- 勝利 → EXP / Gold / 装備ドロップ

**プレイヤーが感じること**:
- 「攻撃 → 反撃 → スキル発動」の応酬で **戦闘ゲーム性** を実感
- 装備ドロップで「同じ名でも違う effects があるかも」興味
- Lv2 になる達成感

**Phase 1 必須**:
- 敵 HP +100% で 3-5 ターン継続
- スキル使用が「あって良かった」となる difficulty

### 30〜60 分: コアループ確立

**画面遷移**:
- `/inventory` で装備差を見る (装備中比 ±N の数値)
- 装備変更 → HUD のステータスが上がる
- もう 1-2 戦
- `/town` でクエスト受注 (掲示板)
- 対象敵を倒す → 進捗 1/3
- HUD 目標表示: 「次の解放: Lv5 で湖畔の街ミルレ」

**プレイヤーが感じること**:
- 「装備で強くなる」のハクスラ快感
- 「次の街が解放される」という発見の予感
- 5-10 戦で Lv5 到達、ミルレ解放の達成感

**Phase 1 必須**:
- `Town.unlockLevel` で街解放 UI (ロック中はグレーアウト + 「Lv5 で開放」表示)
- クエスト受注済みは掲示板から除外
- 「目標 HUD」常時表示

## Day 1 後半 (60 分〜数時間)

### Lv5 達成後の拡がり

**画面遷移**:
- ミルレに移動 → 別の街並み・別 NPC・別敵タイプ
- `/forge` 発見 (Lv5 開放)
- アフィックスのリロール / 強化を試す
- `/shop` で消耗品 (薬草、エリクサー)
- 連戦で Lv6-7

**プレイヤーが感じること**:
- 街移動で世界観の拡がり
- 装備加工で「自分の装備を作る」ハクスラ深化
- まだ見ぬ街への期待

---

## Week 1 (Lv 5〜15) — ビルドの入口

**主要イベント**:
- Lv10 で `/jobs` 開放、転職候補が 3 つ生成
- 転職課題 (定数 3 体討伐) → 達成 → 転職実行
- 過去職に戻れる仕様で「**過去職のスキルを継承スロットに持ち込み**」を発見
- C30 機能: 異カテゴリ MP 1.5x / 熟練度 +5/+10/+15% / チェーンコンボ +10%
- 戦闘でビルドを試す → 効果実感

**画面遷移**:
- `/jobs` → 転職候補 → 課題 → 達成 → 転職
- 過去職へ戻る → 継承スロットに別 archetype のスキルを入れる
- 戦闘で「【継承】[熟練+5%]」タグを見る

**プレイヤーが感じること**:
- 「自分のキャラを設計する」ビルド感覚
- スキルコンボの発見
- 「もう 1 戦してみよう」(熟練度を上げたい)

**Phase 3 必須 (現状動くが体験設計に組み込み)**:
- C30 機能を「ビルド遊び」として体験設計上で位置付け
- 継承スキル UI が分かりやすい配置

---

## Month 1 (Lv 15〜30) — 物語深化

**主要イベント**:
- Mastery クエスト 27 種が Lv15 で開放
- ギルドに招待される / 設立する
- テーマ別ダンジョン 5 種 (忘却の図書館 / 霜帝の塔 / 鏡映の湖底 / 灰の唄の祭壇 / 鐘塔の地下) Lv25-
- 週末ボス T1 (T2 → T3 段階開放)
- シーズンの中心の謎: 手がかり収集
- curated NPC との関係を深める (現状: bio + relations 表示のみ)

**Phase 3 で必要な追加**:
- **物語クエスト**: curated NPC が発行する「○○を△△に届ける」「××の話を聞く」型のクエスト (現状 quest は敵討伐中心)
- **シーズン謎の段階開示**: NPC との会話で手がかり #2-#5 が解禁される条件付きトリガ
- **lore 連動**: 「酒場の主人カイ」と話すと、村医ロサとの関係が会話で示唆される

**プレイヤーが感じること**:
- 「世界の物語が動いている」感覚 (ログインで状況が変わる)
- 仲間との繋がり (ギルド倉庫 / 共闘)
- 自分の進捗が世界に刻まれる感覚 (シーズン解明者の名誉)

## Endgame (Lv 50+) — マルチ統合

**主要イベント**:
- アセンション: Lv1 リセット + 永久ボーナス、世代を進める
- 奈落: 無限階、週次ランキング
- 攻城戦: 30s ターン制 6 アクション、ギルド連携
- ワールドレイド: 街湧き、非同期 DPS race
- 称号コンプ「歩く伝承」(全 90+ 称号)
- シーズン解明者の名誉、`/canon` 年表に名が残る

**プレイヤーが感じること**:
- 「自分のキャラがこの世界で語られる」永続性
- 仲間との連携・競争の頂点
- 次のシーズンへの期待

## 「毎日帰りたくなる」フックの具現化

各フェーズで 1 つ以上のフック:

| フェーズ | フック |
|---|---|
| **Day 1** | 「次の街が解放されてる」/「装備が拾える」/「クエストの進捗」 |
| **Week 1** | 「継承スキルでビルドを試したい」/「熟練度を上げたい」/「転職機会」 |
| **Month 1** | 「シーズンの謎の手がかりが見つかるかも」/「ギルドメンバーが入った」/「週末ボスがリセット」 |
| **Endgame** | 「奈落 F25 から先へ」/「攻城戦の登録期限」/「アセンションでビルドを刷新」 |

このフックが **HUD or town top に毎日変わる「今日の予告」として表示される** べき。
これは Phase 1 Cycle 41 の「目標 HUD」で実装。

## 現状 vs 想定のギャップ

| 観点 | 想定 | 現状 |
|---|---|---|
| 戦闘濃度 | 3-5 ターン | 1 ターン決着 |
| 街解放 | 段階的 (Lv5/10/15...) | 全 115 街即解放 |
| 目標可視化 | HUD で「次にやること」常時表示 | なし |
| クエスト UI | 受注済みは別セクション | 掲示板に出続け |
| 物語クエスト | NPC が発行する関係性ある quest | quest は敵討伐中心 |
| 機能の段階解放 | Lv に応じて menu 露出 | HUD ナビで全機能即見える |

これらは **Phase 1 (Cycle 40-42) で対応**。
