# シーズン詳細 — 中心の謎と手がかり

> 各シーズンの中心の謎は、プレイヤーが手がかりを集めることで全貌が見える設計。
> 本ドキュメントは内部資料として「答え」「設計意図」「次シーズンへの繋がり」をまとめる。
> ゲーム内で表示される手がかりテキストは [`src/lib/seasonRotation.ts`](../../src/lib/seasonRotation.ts) を参照。

---

## Season 1: 灯の年

**中心の謎**: 世界中の塔の最上階で同時に燃え始めた灯火の正体。

### 設定（内部）
- 「灯の年」は 14 年に一度訪れる祝祭年と古老は言うが、実際には誰も確認できない。
- 灯火の真の役割は、影の教団が世界に張った「封印」を緩めるための燃料。
- 解明者は灯火の意味に気付き、塔の頂へ登る選択を迫られる（Cycle 41+ 計画）。

### キーワード
塔 / 鐘 / 紋章 / 禁書 / 井戸 / 灯 / 影 / 封印者 / 薄明

### 解明後のフレーバー（自動 announce 文）
> 「灯火が消えた。もしくは、別の意味で点り続けている。世界はそれを忘れない。」

## Season 2: 鏡の森

**中心の謎**: 鏡の森に映る影は誰のものか。

### 設定（内部）
- 鏡映の湖沼地方に存在する「鏡の森」は、満月の夜に対の世界へ通じる扉が開く。
- 対の世界は本世界の左右が反転した鏡像で、鏡の住人もまた鏡から本世界を眺めている。
- 解明の鍵は **古書店主エラ** が密かに保管する古文書の一節。古書店に何度も通うと
  断片が手に入る（C33-c では設定のみ、実装は未完）。

### キーワード
鏡 / 森 / 影 / 泉 / もう一つ / 映る / 対 / 境界

### 7 手がかり（要旨）
1. 鏡の森で同じ顔の旅人にすれ違う
2. 湖畔ミルレの古井戸で水面の自分が先に手を振る
3. 鏡の森から戻ると左右が入れ替わっている
4. ヴェルナで盗まれた鏡が他の街で誰も買わない
5. 司書の書物の一頁だけが裏表逆
6. アルダの井戸の底に二つ目の月
7. **(final)** 満月時、鏡が対の世界へ通じる扉となる

### NPC との関連
- **古書店主エラ** (ヴェルナ): 鏡の森に関する禁書を所持。
- **異界研究者ノル** (ベルクラート): 鏡像と異界の関連を研究中。
- **書庫司書グレタ** (ベルクラート): 古文書の真贋判定で協力可能。

## Season 3: 灰の唄

**中心の謎**: 灰の唄を歌う者の正体。

### 設定（内部）
- 灰落としの平原に連なる古謡が起源。歌った者は灰になって消えるという伝承。
- 真相は、滅びた古王朝の **王宮魔導師ドラン** が王朝崩壊時に作った鎮魂魔法。
  歌い継ぐことで王朝の魂を世界に留めるが、歌い手も歌の燃料となる。
- アルダの祝祭で歌われる古謡の三番に、同じ旋律が紛れ込んでいるのは、
  かつて王朝の遺民が亡命して伝えた名残。

### キーワード
灰 / 唄 / 詩 / 夜 / 声 / 燃え尽きた / 古き節 / 祝祭

### 7 手がかり（要旨）
1. 子供たちが知らないはずの古い節を口ずさむ
2. ミルレで誰の声でもない女の歌が湖から
3. ヴェルナの吟遊詩人が知らない旋律を歌って倒れる
4. 歌い終えた者は灰の塊を残して消える
5. 古い書物に灰の濃淡で記された楽譜
6. アルダの祝祭古謡三番に同じ旋律
7. **(final)** 歌い継ぐ者がいる限り歌い手の名は灰の中で生きる

### NPC との関連
- **元王宮魔導師ドラン** (ヴェスペル): 真相を最も知る存在。手がかりを進めると会話が深まる。
- **黒衣の使者ヴァレン** (ヴェスペル): 王命を受けて世界を旅しており、彼が運ぶものが灰の唄と関係する可能性。
- **酒場の歌い手ピラ** (ミルレ): 民謡コレクターとして、各地の旋律変化を知る。

## Season 4 以降の展望（未実装、Cycle 41+ 計画）

- ヌル・ゴン・シャズ・ナス が裏で繋がっている設計
- 表向きの教団 vs 影の教団の対立軸
