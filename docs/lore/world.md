### 5 主要都市の役割
1. **始まりの街アルダ** — 巡礼者・新人冒険者の起点。最も平穏で、街の住人同士の関係が密。
2. **湖畔の街ミルレ** — 商業のハブ。両替・港・商会が集まる。物流と情報の集積地。
3. **霧の街ヴェルナ** — 暗部・密儀・賭場の街。教団から逃れた者・密書・禁書が集まる影の中心。
4. **鐘塔の都ベルクラート** — 知識の都。100 年鐘を鳴らし続ける鐘塔があり、書庫・古文書・異界研究の中心。
5. **古王国の都ヴェスペル** — 滅びた王朝の遺構の上に再建された街。王侯文化の名残と遺跡守の街。

## 2. 暦と季節

世界には 30 日 1 ヶ月の暦が用いられる。各シーズン（30 日相当）に世界全体を覆う「中心の謎」が存在し、それが解明されるか期間満了で次シーズンに移る。

### Season 1: 灯の年
- 主題: 燃え続ける灯がもたらす変化
- キーワード: 塔 / 鐘 / 紋章 / 禁書 / 井戸 / 灯 / 影 / 封印者 / 薄明
- 中心の謎: 詳細は `seasons.md` 参照

### Season 2: 鏡の森
- 主題: もう一つの世界を映す鏡像
- キーワード: 鏡 / 森 / 影 / 泉 / もう一つ / 映る / 対 / 境界
- 中心の謎: 鏡の森に映る影は誰の影か

### Season 3: 灰の唄
- 主題: 誰のものでもない歌の謎
- キーワード: 灰 / 唄 / 詩 / 夜 / 声 / 燃え尽きた / 古き節 / 祝祭
- 中心の謎: 灰の唄を歌う者の正体

## 3. 宗教

### 主要教団
- **聖印教団** — 中央高原の聖印の高原を本拠とする多神教団。鐘塔・神官・巡礼の網羅をする。やや権威主義的。
- **影の教団** — 教義に反した者・追放者が密かに継承する裏の信仰。ヴェルナで最も活発。

### 異端
- **異界研究派** — 鐘塔書庫の禁書区画から派生。異界からの召喚・転送魔法を研究中。聖印教団から異端認定済み。
- **不死研究派** — 永遠の命を求める研究者集団。ヴェスペル古王朝崩壊と関連があるという噂。

## 4. 魔導と職業の体系

[`docs/team/CURATED_JOB_BULK.md`](../team/CURATED_JOB_BULK.md) の curated job 100 体が
本世界の「個性的な職業」のリファレンスとなる。8 カテゴリの分類:

- warrior / mage / rogue / cleric / craft / support / heretic / rare

`heretic` は教団からの追放者、`rare` は血統や生まれによる稀有な存在
（半妖精・龍の子・古竜の血など）を表す。

## 5. 古王朝（既に滅びた王権）

ヴェスペルの遺跡を残す王朝。3 代前に滅びたとされ、原因は宮廷魔導師
ドラン以外誰も口にしない。最後の王の遺命を受けた **黒衣の使者ヴァレン**
が今も世界を旅している（curated NPC 参照）。

王朝崩壊の真相は本作のシーズン 4 以降の伏線として埋まっている。
