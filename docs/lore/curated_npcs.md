# curated NPC 関係マップ

> Cycle 33 で導入した手作りユニーク NPC 30 体（5 街 × 6）の関係グラフ。
> ゲーム内では `Npc.relationsJson` に保存され、`/town` ページで展開される。
> 本ドキュメントはマスター資料として「全関係」「内部設計」を一覧化する。
>
> 実データは [`prisma/curatedNpcs.ts`](../../prisma/curatedNpcs.ts) を参照。

## 関係グラフ（明示的な相互関係）

### 始まりの街アルダ — スターターハブ
```
酒場の主人カイ ─── 幼馴染 ─── 村医ロサ
       │
       ├── 息子のような存在 ── 見習い騎士アル
       │
       └── 酒呑み仲間 ─── 鍛冶屋ブルム

村医ロサ ─── 週一の囲碁仲間 ─── 司祭オリヴァ

宿屋の女将リナ ─── (独立、客の記憶のみ)
```
**設計意図**: アルダは新人プレイヤーのホーム。NPC 同士が密に絡むことで
「この街に帰ってきた」感を出す。

### 湖畔の街ミルレ — 商業ハブ
```
商会主ヴェル ─── ライバル兼共犯 ─── 両替商ゾロス
                                       │
織工の娘リン ─── 親友 ─── 酒場の歌い手ピラ

網元の老人タオ ─── (独立、湖の主の伝承)
港の監視員モート ─── (独立、元海賊仲間との葛藤)
```
**設計意図**: 商業 vs 職人 vs 港の 3 軸が並列で動く。

### 霧の街ヴェルナ — 影と密儀の街
```
古書店主エラ ─── 情報源/協力者 ─── 元神官の流れ者ナス
            (Season 2 の鍵)

影の教団内部ライン (内部設計、明示せず):
薬師の老婆ヌル ─── 連絡 ─── 影使いの仲介人ゴン ─── 連絡 ─── 賭場の主シャズ

占い師のミラ ─── (独立、嘘を見抜く力で物語の局面を変える)
```
**設計意図**: 表の関係はエラ↔ナスのみ明示。影の教団ラインは内部設計
として置き、Season 6 (影の教団の動き) で開示される。

### 鐘塔の都ベルクラート — 知識の都
```
鐘番の老人ベルル ─── 共に鐘を守る ─── 巫女のセラフィ

書庫司書グレタ ─── 研究仲間 ─── 異界研究者ノル

時計職人サフォ ─── (独立、機械工としての孤高)
鳥語使いコロ ─── (独立、街中の伝令網を一手に)
```
**設計意図**: ノル↔グレタが Season 5 (異界研究) の入口。
セラフィの神託は ベルル の鐘の鳴り方で発動。

### 古王国の都ヴェスペル — 王朝の名残の都
```
遺跡守ザカリ ─── 旧友 ─── 元王宮魔導師ドラン
                              │
                  王命を共に受けた ─── 黒衣の使者ヴァレン

元王宮料理人テレザ ─── (独立、王の食卓の継承)
石工の頭領ガラム ─── (独立、彫像に魂が宿る伝説)
王宮道化師ピエト ─── (独立、亡命貴族の末裔)
```
**設計意図**: ザカリ↔ドラン↔ヴァレンの 3 人が王朝崩壊の真相を握る
中心人物。3 人の対話が Season 3 (灰の唄) と Season 4 (古王朝の遺命)
の鍵となる。

## クロスタウン関係（内部設計、未明示）

curated NPC データには記録していないが、シナリオ進行で明らかになる関係:

- **元神官ナス（ヴェルナ）↔ 司祭オリヴァ（アルダ）**
  ナスは元アルダ教区の司祭の弟子。オリヴァが破門の儀式を執り行った相手。

- **酒場の主人カイ（アルダ）の娘 ↔ 影使いゴン（ヴェルナ）**
  カイの娘は呪い職に就き、ゴンの仲介で霧の街に身を寄せている。
  カイは知らない、ゴンは黙っている。

- **元王宮料理人テレザ（ヴェスペル）↔ 商会主ヴェル（ミルレ）**
  テレザの妹がヴェルの母親。世代を跨いだ商業ネットワーク。

- **古書店主エラ（ヴェルナ）↔ 異界研究者ノル（ベルクラート）**
  エラが密かにノルに禁書を流している。検閲を避けるため、
  鳥語使いコロが運搬を担う。

これらは将来のサイクル（C34+）でクエスト・噂・ダイアログとして
徐々に開示されていく予定。

## NPC 出典・名前の由来（雑記）

curated NPC の名前は北欧・ラテン・スラブ系の音から組み立てている。
意味は基本的に持たせていないが、響きで地方の文化を伝える設計:

- アルダ (中央高原) — 短い 2-3 音節、日常感のある名前
- ミルレ (湖畔) — 商業的・洗練された響き
- ヴェルナ (霧) — 重い子音、影を感じる響き
- ベルクラート (鐘塔) — 古典的・学者風の響き
- ヴェスペル (古王朝) — 王侯ぽい・古典ラテン的な響き

将来 C31 Phase 3 で curated job を 300 体まで拡張する際も、
同じトーン基準で命名する。
