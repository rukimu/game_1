## 7. 既知の懸念点 (専門評価で指摘された項目)

実機テスト中に**特に注意して観察**すべき項目:

| 観点 | 観察ポイント |
|---|---|
| **Mute enforcement** | Mute された後に chat 送信できてしまう (no-op バグ) |
| **rate limit** | 1 秒以内にチャット連投できてしまう (未配備) |
| **abyss 報酬** | F20+ で報酬が現実離れした額になる (cap なし) |
| **ascension** | 5 世代やっても弱く感じる |
| **PvP 初心者** | 初日で 1500→1300 で挫折する |
| **戦闘 hotkey [2]** | UI と挙動の不一致 (skill select 必要なのに hotkey 即発動) |
| **HUD 密度** | 375px で HP/MP/EXP/title/icon が 5-6 行に伸びる |
| **動的台詞** | 同 NPC を 10 回見ると同じ言い回しに気付く |
