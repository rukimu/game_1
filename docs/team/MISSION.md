# 神ゲープロジェクト ミッション憲章

## 0. 北極星 (North Star)

> **「攻略サイトでは絶対に答えが出せない、毎日帰りたくなるテキストRPG」**

- 唯一無二の "肌触り" を持つ
- 1セッション 30分で「次の戦闘どうしよう」が止まらない
- マルチプレイヤーである必然性がある（ソロでも遊べるが、誰かと関わると世界が広がる）
- "答えのない問い" が常に走っている（シーズンの謎、呪い職、ダンジョンの選択肢）

## 1. 設計指針 (Design Pillars)

1. **不確実性 > 計算可能性**: プレイヤーが攻略を読み切れない仕組みを優先する
2. **個に応じる世界**: クイズ・履歴・職業・季節がプレイヤー固有の物語を生む
3. **協調の必然**: 呪い職解除、攻城戦、シーズン謎の最終手がかりなど、他者と関わる強力な動機を仕込む
4. **テキスト RPG の格**: 1 行 1 行が読み物として価値ある日本語であること
5. **動かないものは作らない**: テーブルだけで未参照のコードは負債。実装するか消すか
6. **公平なゲーム性**: 課金は強さに直結しない。コスメ・利便のみ

## 2. 元の要件との関係

- 元仕様 (会話 1 通目) を「動作する MVP」として満たし済み
- 神ゲー化のために、必要であれば仕様を**変更・削減してよい**（ユーザ許可済み）
- 但し以下は変更不可:
  - クライアントを信用しない (3.1)
  - AI 生成は最終決定に使わない (3.2)
  - 課金は強さに直結しない (4.18)
  - フィールド PK なし

## 3. チーム構成 (Roster)

| 役割 | 担当 | 出力形式 |
| --- | --- | --- |
| **監督 (Director)** | メインスレッド (自分) | 評価結果を統合し、優先度を判断、コミットを承認 |
| **企画 (Game Designer)** | 並列スポーン | 独自性・中毒性・初動 30 分の評価 |
| **数値 (Balance Designer)** | 並列スポーン | 戦闘式・経済・経験値曲線の評価 |
| **物語 (Narrative Designer)** | 並列スポーン | 生成テキスト・世界観・NPC の評価 |
| **技術 (Tech Lead)** | 並列スポーン | スタブ・孤立テーブル・実装抜けの評価 |
| **QA (オンデマンド)** | 必要時スポーン | 実装後の動作確認とリグレッション |

## 4. 運用フロー

```
[Cycle N]
  ├─ 監督: BACKLOG.md を読み、本サイクルのテーマ決定
  ├─ 専門家 (並列): 各観点で評価レポート (各 500-700 語)
  ├─ 監督: 結果を統合し、優先 1-3 件を確定 → BACKLOG.md 更新
  ├─ 実装: 監督が具体的にエッジを切って実装
  ├─ QA (必要時): 動作確認
  └─ 監督: コミット → BACKLOG.md ステータス更新
```

## 5. 完了の定義 (Definition of Done)

- 該当機能が `npm run dev` 起動で実際にプレイ可能
- 神ゲー指針 (1) のうち、関連する柱を強化している
- 既存機能に回帰がない
- BACKLOG.md にステータス更新がある

## 6. 禁止事項

- ユーザに「次どうしますか」と判断を投げ返さない（監督が決める）
- README に古い情報を残さない（変更したら同期）
- 動かない機能を「土台のみ」と誤魔化さない（消すか動かす）
- 過度に大きいリファクタを 1 サイクルで実施しない（小さく刻む）
