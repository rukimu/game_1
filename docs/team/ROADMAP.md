# 神ゲープロジェクト ロードマップ

> **方針**: 監督が次の開発目標を提示し続ける。サイクルを区切らず継続実装する。
> ユーザの停止指示があるまで続ける。

## 神ゲー指針 (再掲)
1. 不確実性 > 計算可能性
2. 個に応じる世界
3. 協調の必然
4. テキスト RPG の格
5. 動かないものは作らない
6. 公平 (課金は強さに直結しない)

## 進行・次サイクル

### Cycle 16 — 闘技場レート
**理由**: 決闘の社会的フィードバック軸。Cycle 6 のランキングを実力指標 (Glicko 簡易) に拡張。
- Duel/Character に rating 列追加
- ランキングを wins から rating に
- 「適正帯」マッチング (±200 rating の相手を suggested に出す)
- 影響: 神ゲー指針 3, 5

### Cycle 17 — NPC が複数プレイヤーを記憶する
- NpcConversation テーブル (npcId × characterId × lastSpokenAt)
- 街訪問時に NPC が「○○もさっきここに来ていた」と教えてくれる
- 影響: 神ゲー指針 2, 3

### Cycle 18 — インベントリ強化 (装備比較ビュー)
- 候補装備にカーソルを当てると、装備中アイテムとの差分 (atk +3 / def -1 等) を表示
- ソート (tier / atk / def / acquiredAt)
- 影響: 神ゲー指針 5

### Cycle 19 — シーズン自動切替
- isCurrent シーズンの endedAt を超えたら、次シーズンを生成 + ロールオーバー
- アーカイブとして既存シーズンの謎結果を保存
- 影響: 神ゲー指針 1 (世界が動く)

### Cycle 20 — モバイル UX 監査
- 全ページを 375px 幅で再点検
- HUD のリンク数が増えすぎている問題 (Cycle 4-15 で +5 リンク) のメニュー化
- 影響: 神ゲー指針 5 + リリース前提

### Cycle 21 — AI プロバイダ実装 (オプション)
- ANTHROPIC_API_KEY が存在する場合に AiContentGenerationService が実テキストを返す
- フォールバック (タイムアウト・エラー) 時はテンプレートに静かに戻る
- 影響: 神ゲー指針 4 (テキスト品質)

### Cycle 22 — Postgres + Redis 移行検証
- prisma schema の datasource を postgresql に切り替えた状態でテスト起動
- Socket.io に Redis adapter を導入し 2 ノード並行起動を確認
- 影響: リリース前提

## 停止条件
- ユーザの明示的な停止指示
- ビルド失敗が解決できない致命的エラー
- 同じセッション内のコンテキスト枯渇
