# コアループ設計

> Cycle 39 (Phase 0) 設計図。**戦闘 1 ターンで何を考え、戦闘後 30 秒で何を見て、街で何をするか** を解像度を上げて記述する。
>
> [`PLAYER_JOURNEY.md`](./PLAYER_JOURNEY.md) のタイムラインに対し、本ドキュメントは「**戦闘 1 周のミクロ体験**」を担当する。
> ハクスラの根幹 = この 1 周が面白いこと。Day 1 の 30〜60 分はほぼこのループで構成される。

---

## ループの全体像

```
[街] ─── 戦いに出る ───→ [戦闘 (3-5 ターン)] ─── 勝利 ───→ [報酬画面] ─── 街帰還 ───→ [装備見直し]
                                  │                            ↓
                                  ↓                       [/forge / /shop]
                              [全滅 → ペナ]                       │
                                                                   ↓
                                                              [次の戦闘へ]
```

各段階の **意思決定の解像度** を以下で定義。

---

## 1. 戦闘 1 ターンの意思決定 (3-5 ターン × 各 5-10 秒)

### 表示されるべき情報

**敵側**:
- 名前 + creatureType (アイコン: humanoid/beast/undead/magic/construct)
- HP バー (絶対値 + %)
- 元素属性 / 弱点属性 (バフで公開された場合)
- 状態異常 (毒 / 火傷 / スタン / 沈黙 / 出血 / 呪い化)
- 次の予告アクション (高難度敵のみ、ヒント程度)

**味方側 (自分)**:
- HP / MP バー
- 装備込みステータス (atk / def / mat / mdf / spd)
- 状態異常
- 利用可能スキル一覧 + cost / CD 残

### 意思決定の流れ

毎ターン以下を判断:
1. **HP が危険か** (< 30%) → 防御 or 回復系スキル
2. **MP が十分か** → スキル使用判断
3. **敵の弱点属性は分かっているか** → 弱点公開系スキル先行 → 属性スキル
4. **連携 (C30 chain combo)** → 直前の skill type と異なる type で +30%
5. **熟練度ボーナス** → よく使うスキルを継続使用 (10/30/50 回で +5/+10/+15%)

### スキル選択 → 対象選択 → 発動 の UX

**現状**:
- スキル ドロップダウンから選ぶ
- 詳細パネルが下に出る
- 敵をクリックして「スキル」ボタン

**改善余地 (Phase 1)**:
- スキル選択時に **対象の弱点との相性プレビュー** が見える
- 連携ボーナスが乗るかどうか **戦闘ログ近辺** で予告される
- キーボードショートカット: 1=攻撃 / 2=スキル / 3=防御 (実装済、ただし 2 は事前選択必要)

### 「考える」を引き出す敵 HP / 難度設計

**Lv1-3** (Day 1 最序盤):
- 敵 HP = 自分 atk × 3-4 程度 → 3-4 ターン
- 敵 atk = 自分 def + 数発耐えられる程度
- スキル 1 発で半分削れる演出 → 「スキル使う価値」を体感

**Lv4-10**:
- 敵 HP = 自分 atk × 4-6
- 状態異常を仕掛けてくる敵が出始める
- スキル MP コスト管理が重要に

**Lv10+**:
- パーティ前提の敵が混じる
- ボス級は 6-8 ターン
- ビルドで明確な差が出る (弱点突き / 連携 / 熟練度)

## 2. 戦闘後 30 秒 — 報酬画面で何を見るか

### 表示されるべき情報

**経験値**:
- 獲得 EXP + 連戦ボーナスの内訳 (基本 N + 連勝 +20% など)
- HUD のレベルバー更新、Lv UP したら祝福演出
- 「次の Lv まで N EXP」

**Gold**:
- 獲得 + 連戦ボーナス
- 累計表示 (HUD)

**装備ドロップ**:
- ティア (common/rare/epic/legendary) で色分け
- displayName (例: 「燻し銀の 古びた剣の継承」)
- 「装備中の同 slot より +N atk / -M def」**即比較**

**進捗フィードバック**:
- クエスト進捗 (1/3 → 2/3)
- アチーブメント獲得 (該当時)

### プレイヤーが感じる「次へ」の動機

- 装備が良ければ → 「装備変更したい」
- クエスト進捗 2/3 → 「あと 1 戦」
- Lv UP 直前 → 「あと 1 戦で Lv UP」
- スキル熟練度が 9 → 「あと 1 回で +5%」

→ **これら全てを HUD or 戦闘後画面で可視化** する。

---

## 3. 街帰還後の意思決定 (1-3 分)

### プレイヤーの選択肢

1. **装備見直し** (`/inventory`)
   - 新装備を装備するか
   - tier フィルタ / slot フィルタ / ソート
   - 装備中比 ±N で選びやすい

2. **加工** (`/forge`、Lv5+)
   - リロール (アフィックス変える) / 強化 (ティア上げる)
   - 素材 5 個消費、ゴールド消費
   - プレビューで結果確認

3. **回復** (`/town` の宿屋)
   - HP / MP 全回復、Gold 消費
   - 街の innFee による

4. **消耗品** (`/shop`)
   - 薬草 / エリクサー など

5. **クエスト** (`/town` 掲示板)
   - 受注 / 進捗確認 / 完了報告

6. **次の戦闘** (`/town` の「戦いに出る」)

### Day 1 で押さえるべきフロー

**最小 5 ステップループ**:
1. 街で「戦いに出る」
2. 戦闘 → 勝利
3. 装備拾う
4. 街帰還 → 装備見直し
5. 次の戦闘

これが **3-5 周** で 30 分。Lv5 解放、ミルレへ移動、別エリアで継続。

## 4. 全滅時のペナルティとリカバリ

### 現状
- Gold -10%
- HP/MP = 1
- 街に強制送還

### 体験設計上の意味
- 「死んでも次がある」ペナルティの軽さ → カジュアルさ
- ただし「装備差を意識せずに突っ込むと死ぬ」リスクは保たれる
- ダンジョンでは累積報酬の半分喪失でメリハリ

---

## 5. 体感「強くなった」の演出ポイント

ハクスラの根本的な快感は「**前より強くなった**」の体感。これを演出するポイント:

### 装備変更時
- インベントリで装備した瞬間、HUD のステータスが視覚的に更新 (色付き +N)
- 「次の戦闘で何ターン早く倒せるか」予想 (上級は数値で表示)

### Lv UP 時
- 演出 (画面フラッシュ / 効果音)
- ステータス上昇内訳表示

### 転職時 (Lv10+)
- 元職スキル → 新職スキルの差分表示
- 継承スロット解放のお知らせ

### 熟練度 +5% 達成時
- 戦闘ログで「[熟練+5%] が初めて発動！」と告知 (1 回限り)

### アフィックス強化時
- forge 完了画面で before/after 比較

## 6. ボス戦・特殊戦闘の差別化

通常戦闘との違い:

### 本日のボス (Lv5+、パーティ単位 1 日 1 回)
- 6-8 ターン
- 弱点公開が重要
- 確定 epic/legendary ドロップ
- 初討伐告知

### 週末ボス T1/T2/T3 (Lv15+ 段階開放)
- T1 撃破 → T2 開放 → T3 開放
- T2+ で 2 個ドロップ
- T3 伝説確定

### ワールドレイド (街湧き)
- 非同期 DPS race
- 個別 CD (攻撃 5s / 特技 15s / 回復 10s)
- 貢献度ランキング報酬

### 攻城戦 (Lv15+、ギルド単位)
- 30s ターン制 6 アクション
- ギルマス「号令」/ サブ「治療」

これらを**いつ初めてプレイヤーに体験させるか**は [`PLAYER_JOURNEY.md`](./PLAYER_JOURNEY.md) で定義。
基本ループから派生する **時々の特別戦闘** として配置。

## 7. Phase 1 で必須となる修正 (戦闘濃度関連)

### A. 敵 HP / atk バランス調整 (必須)
- Lv1-3: 敵 HP +100% 推奨 (現状の倍)
- Lv4-10: 敵 HP +50%
- Lv10+: 現状維持
- → 1 ターン決着問題の解消

### B. 戦闘 UI の情報密度 (推奨)
- 敵に creatureType アイコン表示 (現在 32 SVG あり、未配備)
- 状態異常をアイコンで表示
- スキル詳細パネルに「対象の弱点との相性」表示

### C. 戦闘後画面の整理 (推奨)
- ドロップ装備の装備中比を即表示
- 「次の Lv まで N」の HUD 更新を強調
- クエスト進捗が変わったら通知

### D. 連戦ボーナスの可視化 (推奨)
- 現在 3 連勝で +20% EXP / +10% Gold
- HUD に「現在 X 連勝、+X% bonus」常時表示
