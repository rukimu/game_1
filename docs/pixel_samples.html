Cycle 35 ピクセルアート方向性サンプル

3 案それぞれで「戦士アイコン」「スライム（敵）」「剣（装備）」を描き比べ。
Cycle 35 ではこの方針で 職業 9 / 敵 25+ / 装備 18+ / ボス 30+ を量産する想定。

案 1 — シルエット＋アクセント（黒 + 黄金、3 色）

既存 UI（黒地+黄色金）と完全マッチ。軽量、統一感最優先。
個性は控えめだが「表記の補助アイコン」として確実に機能。

shading なしのベタ塗りで識別性◎。AI バッチ生成と相性が良い。
ROADMAP_MAX の 16/32/48/64 サイズ階層に最も自然に乗る。

案 3' — モダン・インディー風（HD-2D 寄り、24 色 cohesive palette） ★ 推奨（リファイン版）

Sea of Stars / Octopath Traveler 系の現代インディー寄り。1px 黒輪郭 + 4 段階 shading + 統一 palette。
プロポーションを強化（兜 + 鎧 + 脚 + ブーツが明確）、暖色＋冷色の対比でキャラ感を出す。
重い分、curated NPC・curated job の個性表現に十分耐える。
palette (24 色):

戦士 (32×32)
スライム (32×32)
剣 (32×32)

案 4 — HD-2D 48×48 リファイン（顔出し・縦長プロポーション） ★ オクトパス寄り再挑戦

案 3' は 32×32 全身を試したが、頭でっかちで「棒立ちのバイザー兜」にしか見えなかった。
HD-2D 系は顔出し（兜なし or オープンヘルム）+ 縦長 + 表情ありが特徴。
48×48 にスケールし、髪・顔・赤の肩当て・銀の鎧・金の胸章・腰ベルト・革ブーツで
「これは戦士」とすぐ読み取れる構成にしてみた。

戦士 (48×48)

案 5 — Octopath 風リファレンス再現挑戦（28×40、慎重版） ★ 真面目にやり直し

ユーザー提示のオクトパス風リファレンスを観察して再構成:
スパイキーな黒髪 / 片目隠し（右目だけ青く見える）/ 黒革ベスト + 銀ショルダー /
茶色のベルト + ポーチ / ダークグレーの脚 / 茶色ブーツ。
プロのアーティストが描いた本物には届かないかもしれませんが、これでも違和感あれば
手書きドット絵は諦めて game-icons.net 等の流用に切り替えるのが現実的です。

戦士 (28×40)
